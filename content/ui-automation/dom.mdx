## What this lesson covers

This module covers the **DOM** and how to write locators that survive UI churn.

- Accessibility trees vs CSS selectors
- Stable test ids
- Debugging a locator that flakes

## Outcome

After this lesson you will be able to choose a locator strategy that stays stable.
